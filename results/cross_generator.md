# Cross-generator transfer matrix (synthetic -> real instance retrieval)

Queries = a twin set's synthetic clips (test split unless noted); gallery = the FULL
real test set of the same splits (N and chance = 1/N per row). `inst_sao` = the
instance head trained on SAO(0.6) twins; `kfold-unseen` = the 5 leave-classes-out
instance heads pooled over their unseen categories (the paper's headline protocol).
`fidelity` = mean frozen CLAP cosine(twin, its real source).

## Interpretation (2026-07-01 run)

**Audio-conditioned rows (sao45/sao06/sao75, aldm).**
1. *Within the SAO family the mapping transfers across operating points.* The kfold
   instance heads were trained only on noise-0.6 twins, yet on unseen categories they hit
   R@1 0.862 / 0.728 at noise 0.45 / 0.75 (frozen: 0.696 / 0.511) — the +0.17..+0.22
   instance-head margin is stable across the fidelity axis, so the paper's result is not
   an artifact of one operating point.
2. *Across generator families the learned correspondence transfers only weakly.* On
   AudioLDM twins the SAO-trained head lifts R@1 from 0.061 to just 0.085 (kfold-unseen
   0.077); the reverse cell is worse — the ALDM-trained head scores 0.523 on SAO twins,
   BELOW frozen (0.611). Training on ALDM twins does learn *something* generator-specific
   (0.147 on its own twins, 2.4x frozen), so an instance mapping is learnable for ALDM,
   but each head encodes its own generator's rendering map rather than a
   generator-general one.
3. *Caveat: fidelity is confounded with family.* ALDM's measured twin fidelity (0.40) is
   far below every SAO point (0.69-0.78) and ~10% of its twins are degenerate
   (cos < 0.2 to source), so the weak transfer mixes "different renderer" with "much
   noisier twin"; on the SAO-internal fidelity spectrum (restricted balanced gallery),
   frozen R@1 at fid 0.55 (n12) was 0.273 and collapsed by fid ~0.1 — ALDM's 0.061 at
   fid 0.40 sits roughly on that downward trend rather than clearly below it.

**Text-only rows (woosh, el).** Woosh replicates the ElevenLabs failure almost exactly
(frozen R@1 0.023 vs EL 0.024; heads do not help: 0.012 / 0.027), despite both twin sets
being category-appropriate (fidelity ~0.55 = category-level CLAP similarity). The
text-only instance-correspondence failure is therefore NOT model-specific: captioning a
clip and regenerating from text discards the instance identity regardless of the
generator. Instance-level pairing requires conditioning on the source AUDIO.
